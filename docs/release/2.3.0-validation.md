## Alcance y límites

Antes de publicar se verificaron arranque saludable, `Validate` y `Recreate` de MySQL Core en una instalación local. La publicación **no instaló ni ejecutó el MSI público** en ese equipo. Siguen sin prueba manual el ciclo ordinario de parada/arranque del Core y una aplicación PHP real. La restauración completa permanece bloqueada para el layout replicado; el backup completo requiere una parada limpia. El MSI no migra datadirs anteriores y no habilita VirtioFS. La réplica NTFS no sustituye un backup independiente.
