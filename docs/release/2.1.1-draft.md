# WSDD 2.1.1

WSDD 2.1.1 is a patch release candidate for manual validation. It focuses on the project
table layout and on persisting container configuration fixes in source-controlled Docker
assets instead of applying manual changes to an installed environment.

## Project UI

- Reduces the Projects table to the columns needed for scanning: name, domain, PHP, and
  toolbox.
- Moves SSL status and project actions into the project toolbox.
- Keeps Deploy and Remove wired to the existing project deployment and confirmation flows.
- Avoids the unnecessary horizontal scroll caused by action columns when many projects are
  installed.

## Docker Runtime Configuration

- Adds a source-controlled `proxy.conf` for the nginx proxy defaults used by WSDD.
- Mounts `proxy.conf` from `init.yml` into `/etc/nginx/proxy.conf`.
- Regenerates the embedded Docker structure ZIP after changing Docker assets.
- Enables `mysqli` in the PHP 5.6, 7.2, 7.4, 8.1, 8.2, 8.3, and 8.4 images.
- Adds project domain self-resolution through service-level `extra_hosts` entries in
  generated `options.phpXX.yml` files.
- Preserves non-WSDD `extra_hosts` entries when removing a project from options files.
- Copies the mkcert root CA into the Docker SSL directory and mounts it into PHP containers as
  a trusted certificate authority.
- Refreshes container CA trust during PHP container startup without blocking normal startup.

## Issues

- Addresses GitHub issue `#12` by moving local HTTPS/PHP container fixes into WSDD-managed
  Docker configuration files.
- Addresses GitHub issue `#13` by adding a persistent nginx-proxy timeout configuration path.

- `$env:WSDD_SKIP_WINDOWS_MANIFEST='1'; cargo test --workspace`
