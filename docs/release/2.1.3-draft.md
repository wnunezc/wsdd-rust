# WSDD 2.1.3

WSDD 2.1.3 is a patch release candidate for manual validation after `2.1.2`.

## Runtime Rebuild

- Keeps the installed-environment reconciliation introduced in `2.1.2`.
- Ensures Deploy rebuilds the PHP runtime image with `docker compose up --build --force-recreate`
  after WSDD synchronizes managed PHP Dockerfiles and compose files.
- Fixes the case where local Dockerfiles were updated but an existing PHP container kept running
  from an older image without new extensions such as `mysqli`.
- Preserves project volumes and project entries while rebuilding the shared PHP runtime container.

## Validation

- `cargo fmt --all -- --check`
- `cargo check --workspace`
- `cargo clippy --workspace -- -D warnings`
- `$env:WSDD_SKIP_WINDOWS_MANIFEST='1'; cargo test --workspace`
- `cargo wix-msi --nocapture`

Manual validation: install the MSI, open WSDD, then run Deploy for one project on the affected PHP
version so the shared PHP runtime is rebuilt from the reconciled Dockerfile.
