# WSDD 2.1.2

WSDD 2.1.2 is a patch release candidate for manual validation after `2.1.1`.

## Installed Environment Reconciliation

- Synchronizes WSDD-managed PHP Dockerfiles into an existing
  `C:\WSDD-Environment\Docker-Structure` tree during startup.
- Re-renders PHP `webserver.phpXX.yml` files from saved settings/secrets, preserving Webmin
  credentials and Xdebug state.
- Backfills legacy Webmin credentials for older installs when needed so PHP compose templates can
  be rendered safely.
- Repairs existing project `options.phpXX.yml` files through the same idempotent project options
  path used by deploy.
- Preserves local projects, SSL certificates, MySQL data, Docker volumes, and existing
  project-specific options entries.

## UI

- Applies the same compact table treatment to Containers that was already applied to Projects.
- Keeps the Containers table focused on name, status, and toolbox.
- Moves Start, Stop, and Restart into the container toolbox.

## Validation

- `cargo fmt --all -- --check`
- `cargo check --workspace`
- `cargo clippy --workspace -- -D warnings`
- `$env:WSDD_SKIP_WINDOWS_MANIFEST='1'; cargo test docker_deploy::templates::tests --workspace`
- `$env:WSDD_SKIP_WINDOWS_MANIFEST='1'; cargo test yml::tests --workspace`
- `$env:WSDD_SKIP_WINDOWS_MANIFEST='1'; cargo test --workspace`

Manual validation is expected by installing the generated MSI over an existing WSDD environment
and opening WSDD once so the startup reconciliation runs.
